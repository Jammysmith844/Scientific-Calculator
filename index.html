How to use

  • Click or tap any key to build an expression. Press = to evaluate.
  • Keyboard support: type digits and operators directly. Use Enter to evaluate, Backspace to delete, Esc to clear.
  • Angle unit: toggle between DEG and RAD using the button in the top-right of the display. Trig functions respect this setting.
  • Parentheses: use ( and ) to control evaluation order.
  • Power: use xʸ for exponents — e.g., 2 xʸ 10 gives 1024. You can also type ^ on the keyboard.
  • Constants: π and e insert their numeric values into the expression.

Good to know

  • Results use double-precision floating-point arithmetic, which is accurate to about 15–17 significant digits. Tiny rounding differences (e.g., 0.1 + 0.2 = 0.30000000000000004) can occur — this is normal for all computers.
  • Very large results are shown in exponential notation when they exceed the display's comfortable width.
  • Division by zero returns "Undefined" rather than throwing an error.
  • Factorial works for non-negative integers up to 170. Inputs above that overflow to Infinity.
  • This is not a symbolic algebra system. It evaluates numeric expressions only.

Frequently asked questions

Why does sin(30) give 0.5 in DEG mode but something different in RAD mode?

Degrees and radians are different ways to measure angles. 30° equals π/6 radians (≈ 0.5236). The calculator applies the trig function to whichever unit is selected, so you'll get different numeric results.

How do I calculate a negative number?

Use the ± key to negate the current value, or type a minus sign. For example, to compute −5² (which is −25, not 25), enter ± 5 xʸ 2.

Does the calculator remember previous results?

Yes. After you press =, the result stays on the display. You can continue with another operator to use it in a new expression, or press AC to clear and start fresh.

What does "mod" do?

The mod key returns the remainder of a division. For example, 17 mod 5 = 2 because 17 = 3×5 + 2.

Is the calculator accurate enough for real work?

Yes, for most everyday scientific, engineering, and financial calculations. It uses IEEE 754 double-precision arithmetic, the same standard used by most programming languages and spreadsheet software.

Does this work offline?

Once the page has loaded, it works fully offline — all logic is local JavaScript with no external calls.

Limitations

This calculator performs numeric evaluation only. It does not simplify symbolic expressions, solve equations, or handle matrices and complex numbers. For those tasks, a computer algebra system such as a graphing calculator or a math software package is more appropriate.
